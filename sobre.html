1. Estrutura Básica do HTML

Cabeçalho (head)


<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Prog. Master Max</title>
  <link href="https://fonts.googleapis.com/css2?family=Cinzel&family=Open+Sans&display=swap" rel="stylesheet">
  <link href="style.css" rel="stylesheet">
</head>
  • <!DOCTYPE html>: Define que este é um documento HTML5.
  • <html lang="pt-BR">: Define o idioma da página como português do Brasil.
  • <meta charset="UTF-8">: Garante que o navegador entenda caracteres especiais e acentos.
  • <meta name="viewport"...>: Faz a página se adaptar a diferentes tamanhos de tela.
  • <title>: Define o título que aparece na aba do navegador.
  • <link>: Importa fontes do Google e o arquivo CSS de estilos.

6. JavaScript (script.js)

Controle de Tema Claro/Escuro


// Quando a página carrega
document.addEventListener('DOMContentLoaded', function() {
  // Elementos importantes
  const themeToggle = document.getElementById('theme-toggle');
  const body = document.body;
  
  // Aplica o tema escolhido
  function applyTheme(theme) {
    if (theme === 'dark') {
      body.setAttribute('data-theme', 'dark');
      themeToggle.textContent = '☀️';
    } else {
      body.removeAttribute('data-theme');
      themeToggle.textContent = '🌙';
    }
  }
  
  // Verifica qual tema usar
  function checkTheme() {
    const savedTheme = localStorage.getItem('theme');
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    return savedTheme || (prefersDark ? 'dark' : 'light');
  }
  
  // Aplica o tema inicial
  applyTheme(checkTheme());
  
  // Alterna entre temas quando clicado
  themeToggle.addEventListener('click', function() {
    const currentTheme = body.getAttribute('data-theme') === 'dark' ? 'light' : 'dark';
    applyTheme(currentTheme);
    localStorage.setItem('theme', currentTheme);
  });
});

Controle da Barra Lateral


// Toggle da barra lateral
const barraToggle = document.getElementById('barraToggle');
const barraLateral = document.querySelector('.barra-lateral');

barraToggle.addEventListener('click', function() {
  barraLateral.classList.toggle('expandida');
  
  // Atualiza posição do botão
  if (barraLateral.classList.contains('expandida')) {
    this.style.left = '305px';
  } else {
    this.style.left = '85px';
  }
});

Resumo de Funcionamento

  • Estrutura: O HTML organiza o conteúdo em cabeçalho, barra lateral, conteúdo principal e rodapé.
  • Estilos: O CSS define cores, tamanhos e posições de todos os elementos.
  • Interatividade: O JavaScript controla:
    • Alternância entre temas claro/escuro
    • Expansão/recolhimento da barra lateral
    • Transições suaves entre estados
  • Responsividade: O site se adapta a diferentes tamanhos de tela usando media queries.

Cada parte do código trabalha em conjunto para criar uma experiência de aprendizado interativa e acessível para iniciantes em programação web.
